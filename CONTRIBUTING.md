# Contributing to Balatro Multiplayer

## Types of Contributions

We encourage people open PRs or issues related to the following features:
- Bug fixes
- Performance improvements
- Quality of Life
- Website improvements
- Localization

Otherwise, most other types of contributions we suggest opening an issue first to discuss if the feature fits within the vision of Balatro Multiplayer, including:
- Changes to ratings, ranked or seasons
- Changes to moderation, chat filtering or anti-cheat
- New RPCs, or changes to the wire contract with the client mods (these also need a matching change in [BalatroMultiplayerAPI](https://github.com/Balatro-Multiplayer/BalatroMultiplayerAPI))
- New Feature

## Security

Do not report a security problem in a public issue. Contact the maintainers in private on [Discord](https://discord.gg/balatromp).

## Contribution Guidelines

You are welcome to use AI as a tool in your contributions, but:
1. Communicate with us yourself, it is fine if you write the code with AI but I don't want to read your PR written entirely by Claude that is 100 lines when it could be 4.
2. Ensure the contributions are well tested and let us know how you tested the feature and how we can reproduce what you did.
