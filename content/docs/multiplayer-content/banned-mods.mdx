---
title: Banned Mods
description: Banned mods for Balatro Multiplayer.
---

Do not use these mods in ranked/queue.

[View approved mods](/docs/multiplayer-content/approved-mods)

General ban rules:

- Mods that add non-multiplayer gameplay content (new jokers/tarots/planets/etc.) are banned.
- Mods that increase speed above 4x are banned.
- Mods that reveal hidden card/deck info (including top-deck preview or misprint-tech helpers) are banned.

Extra banned mods list: **9** entries.

| Name | Reason | Approved Alternative |
| --- | --- | --- |
| Incantation | Allows stacking consumables beyond consumable slots | - |
| Brainstorm | Save states | - |
| Divvy's Preview or DVPreview | Gives more information than is available to the player | Score Preview Integration |
| Fantom's Preview | Conflicts with Multiplayer due to Score Preview Integration | Score Preview Integration |
| Aura | Not actually banned but will crash if you copy a flash card | - |
| NotJustYet | Allows you to farm past the blind cap | - |
| Showman | In-game seed analysis | - |
| Tag Preview | Gives more information than is available to the player | - |
| QoL Bundle | Changes aspects of the game, not QoL in a Multiplayer context | - |
